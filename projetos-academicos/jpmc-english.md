# JPMC English

## Contexto

Projeto desenvolvido na disciplina **Projeto — Trabalho de Conclusão de Curso**, no 8º semestre do curso de Sistemas de Informação. O repositório é derivado do template de TCC da PUC Minas.

## Objetivo

O projeto propõe um sistema de gestão estratégica para a JPMC English, uma microempresa de aulas particulares de inglês. A solução centraliza dados de alunos, aulas e pagamentos e apoia a geração de indicadores sobre frequência, inadimplência, ticket médio, tempo de permanência e perfil dos estudantes.
