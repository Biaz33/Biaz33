# Sistema de aluguel de quadras esportivas

## Contexto

Projeto acadêmico em grupo mantido no repositório público da organização ICEI-PUC Minas. O sistema reúne funcionalidades de aluguel, agendamento e gestão de quadras esportivas.

## Estrutura técnica

O repositório contém um frontend em Next.js e TypeScript, além dos módulos `gestao-agendamento`, `gestao-quadras` e `microservice-usuario`. As linguagens detectadas no projeto incluem Java, TypeScript, CSS, Dockerfile e JavaScript.
