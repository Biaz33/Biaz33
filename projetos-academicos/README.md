## Observação sobre os arquivos-fonte

O projeto **Bem no Trabalho** possui código-fonte no repositório acadêmico público da organização e documentação complementar no repositório pessoal. Os demais projetos foram desenvolvidos em grupo; o catálogo descreve a participação da Bianca e mantém os links para os repositórios originais, sem atribuir autoria individual sobre o trabalho completo.

Para adicionar outros projetos da faculdade, basta incluir nesta pasta o código-fonte ou o link do respectivo repositório, junto com um README contendo objetivo, participação, tecnologias, aprendizados e instruções de execução.
